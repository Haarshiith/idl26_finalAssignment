# Technical Audit Log: Pipeline Reconstruction

This document itemizes all critical failures discovered in the BioHealth Diagnostics Global machine learning pipeline, documenting the root causes and applied mathematical/structural corrections.

| Issue ID | File Name | Manifestation (The Error) | Mathematical / Logical Root Cause | Implemented Structural Correction | Git Commit Hash |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 001 | `data.py` | Validation accuracy is artificially high and untrustworthy. | The training array (`data_dict['train_images']`) was never truncated after extracting the validation split, causing 100% of the validation set to leak into the training environment. | Applied list slicing `[:val_start]` to explicitly isolate the training bounds from the validation boundaries. | 54844ed |
| 002 | `Code/fit.py` | Loss fails to converge properly, explodes, or fluctuates wildly during training. | Gradients were not zeroed out between batches (`optimizer.zero_grad()` was missing). This caused gradients to accumulate infinitely across iterations, corrupting the parameter weight updates. | Injected `self.optimizer.zero_grad()` inside the training batch loop prior to the backward pass. | b25b403 |
| 003 | `Code/data.py` | `TensorDataset` throws a shape mismatch error during dataset instantiation. | `train_data` was truncated to prevent validation leakage, but `train_labels` was not, resulting in arrays of unequal lengths. | Applied list slicing `[:val_start]` to `train_labels` to match the data dimensions. | e5b2183 |
| 004 | `Code/models.py`, `Code/train.py` | Model acts as a linear transformation; ResNet18 throws `NoneType` error; network fails to learn. | Activation was hardcoded to `Identity`; `ResNet18.forward()` lacked a `return` statement; `train.py` used a sabotaged `drop_rate` of 0.99. | Created `config.json`, refactored model to accept dynamic activation, added `return` to classifier, and restored `drop_rate` to 0.5. | e5b2183 |
| 005 | `Code/train.py` | Pipeline execution crashes instantly with `ModuleNotFoundError: No module named 'Code'`. | Absolute imports utilizing the `Code.` prefix failed because executing the script directly sets the script's parent directory as the root path, breaking the module resolution. | Refactored absolute imports to direct local sibling imports (e.g., `from data import get_loaders`). | d47bb4d |
| 006 | `Code/data.py` | Pipeline crashes with `FileNotFoundError` before training begins. | The dataloader dynamically appended a non-existent `_data` suffix to the file path constructor. | Removed `_data` from the f-string in `Path` resolution to match actual target filenames. | 6738177 |
| 007 | `config.json` | `RuntimeError` during forward pass due to weight/input channel dimension mismatch (expected 3, got 1). | The network was initialized expecting 3-channel RGB inputs, but the new `organs.pt` dataset consists of 1-channel grayscale images. | Updated the global configuration to initialize the model with `CHANNELS: 1`. | 0a07f84 |
| 008 | `Code/fit.py` | `RuntimeError: 0D or 1D target tensor expected` crashes the pipeline during loss calculation. | Target labels were loaded from the dataset as 2D column tensors (and potentially float types), which violates the strict 1D `int64` requirement of `nn.CrossEntropyLoss()`. | Appended `.squeeze().long()` to the label tensors in both the training and evaluation loops to flatten the dimensions and cast to integers. | 1cd9058 |
| 009 | `Code/fit.py` | Resource consumption is entirely unmonitored, preventing efficiency verification. | The baseline pipeline lacked an infrastructure to measure computational and memory footprints, which is an anti-pattern for sustainable ML development. | Injected `time` tracking and `torch.cuda.max_memory_allocated` into the training and evaluation loops to capture duration, latency, and peak VRAM. | f1382c8 |
| 010 | `Code/models.py`, `config.json` | The default `ResNet18` architecture is computationally expensive and misaligned with the Green Initiative efficiency requirements. | Over-parameterized network designed for complex ImageNet tasks leads to unnecessary VRAM consumption and high inference latency for simple 1-channel data. | Developed and integrated `EcoResNet`, a downscaled architecture with heavily reduced channel width and block depth. Updated `config.json` to route data through the new model. | 4432441 |
| 011 | `Code/transfer.py` | `EcoResNet` fails to meet the strict 83% test accuracy requirement on the `orgs` dataset. | Training a deep architecture from scratch on a highly constrained dataset is an anti-pattern that prevents robust feature extraction and causes suboptimal generalization. | Engineered a Knowledge Transfer pipeline to pre-train feature weights on the `cells` dataset, freeze the network backbone, and fine-tune only the classifier on the `orgs` data. | 2fd6e66 |
| 012 | `Code/fit.py` | Knowledge transfer crashes with a `RuntimeError` due to channel size mismatch between source and target datasets. | The `cells` dataset (3-channel RGB) was fed into `EcoResNet` initialized for 1-channel grayscale inputs, violating matrix dimensions. | Injected dynamic channel alignment logic using `images.mean(dim=1)` to collapse RGB data to grayscale dynamically based on the model's first parameter layer shape. | `[Pending]` |
