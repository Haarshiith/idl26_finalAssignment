# Technical Audit Log: Pipeline Reconstruction

This document itemizes all critical failures discovered in the BioHealth Diagnostics Global machine learning pipeline, documenting the root causes and applied mathematical/structural corrections.

| Issue ID | File Name | Manifestation (The Error) | Mathematical / Logical Root Cause | Implemented Structural Correction | Git Commit Hash |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 001 | `data.py` | Validation accuracy is artificially high and untrustworthy. | The training array (`data_dict['train_images']`) was never truncated after extracting the validation split, causing 100% of the validation set to leak into the training environment. | Applied list slicing `[:val_start]` to explicitly isolate the training bounds from the validation boundaries. | 54844ed |
| 002 | `Code/fit.py` | Loss fails to converge properly, explodes, or fluctuates wildly during training. | Gradients were not zeroed out between batches (`optimizer.zero_grad()` was missing). This caused gradients to accumulate infinitely across iterations, corrupting the parameter weight updates. | Injected `self.optimizer.zero_grad()` inside the training batch loop prior to the backward pass. | b25b403 |
| 003 | `Code/data.py` | `TensorDataset` throws a shape mismatch error during dataset instantiation. | `train_data` was truncated to prevent validation leakage, but `train_labels` was not, resulting in arrays of unequal lengths. | Applied list slicing `[:val_start]` to `train_labels` to match the data dimensions. | e5b2183 |
| 004 | `Code/models.py`, `Code/train.py` | Model acts as a linear transformation; ResNet18 throws `NoneType` error; network fails to learn. | Activation was hardcoded to `Identity`; `ResNet18.forward()` lacked a `return` statement; `train.py` used a sabotaged `drop_rate` of 0.99. | Created `config.json`, refactored model to accept dynamic activation, added `return` to classifier, and restored `drop_rate` to 0.5. | e5b2183 |
| 005 | `Code/train.py` | Pipeline execution crashes instantly with `ModuleNotFoundError: No module named 'Code'`. | Absolute imports utilizing the `Code.` prefix failed because executing the script directly sets the script's parent directory as the root path, breaking the module resolution. | Refactored absolute imports to direct local sibling imports (e.g., `from data import get_loaders`). | d47bb4d |
| 006 | `Code/data.py` | Pipeline crashes with `FileNotFoundError` before training begins. | The dataloader dynamically appended a non-existent `_data` suffix to the file path constructor. | Removed `_data` from the f-string in `Path` resolution to match actual target filenames. | 6738177 |
| 007 | `config.json` | `RuntimeError` during forward pass due to weight/input channel dimension mismatch (expected 3, got 1). | The network was initialized expecting 3-channel RGB inputs, but the new `organs.pt` dataset consists of 1-channel grayscale images. | Updated the global configuration to initialize the model with `CHANNELS: 1`. | 0a07f84 |
| 008 | `Code/fit.py` | `RuntimeError: 0D or 1D target tensor expected` crashes the pipeline during loss calculation. | Target labels were loaded from the dataset as 2D column tensors (and potentially float types), which violates the strict 1D `int64` requirement of `nn.CrossEntropyLoss()`. | Appended `.squeeze().long()` to the label tensors in both the training and evaluation loops to flatten the dimensions and cast to integers. | 1cd9058 |
| 009 | `Code/fit.py` | Resource consumption is entirely unmonitored, preventing efficiency verification. | The baseline pipeline lacked an infrastructure to measure computational and memory footprints, which is an anti-pattern for sustainable ML development. | Injected `time` tracking and `torch.cuda.max_memory_allocated` into the training and evaluation loops to capture duration, latency, and peak VRAM. | f1382c8 |
| 010 | `Code/models.py`, `config.json` | The default `ResNet18` architecture is computationally expensive and misaligned with the Green Initiative efficiency requirements. | Over-parameterized network designed for complex ImageNet tasks leads to unnecessary VRAM consumption and high inference latency for simple 1-channel data. | Developed and integrated `EcoResNet`, a downscaled architecture with heavily reduced channel width and block depth. Updated `config.json` to route data through the new model. | 4432441 |
| 011 | `Code/transfer.py` | `EcoResNet` fails to meet the strict 83% test accuracy requirement on the `orgs` dataset. | Training a deep architecture from scratch on a highly constrained dataset is an anti-pattern that prevents robust feature extraction and causes suboptimal generalization. | Engineered a Knowledge Transfer pipeline to pre-train feature weights on the `cells` dataset, freeze the network backbone, and fine-tune only the classifier on the `orgs` data. | 2fd6e66 |
| 012 | `Code/fit.py` | Knowledge transfer crashes with a `RuntimeError` due to channel size mismatch between source and target datasets. | The `cells` dataset (3-channel RGB) was fed into `EcoResNet` initialized for 1-channel grayscale inputs, violating matrix dimensions. | Injected dynamic channel alignment logic using `images.mean(dim=1)` to collapse RGB data to grayscale dynamically based on the model's first parameter layer shape. | 5e523a6 |
| 013 | `Code/transfer.py` | Fine-tuning phase yields catastrophic accuracy drop (~22%) and extremely high initial loss. | The classifier layer retained the pre-trained weights mapped to the `cells` dataset. The network suffered from catastrophic interference, struggling to unlearn old mappings. | Reinitialized `model.classifier` as a fresh `nn.Linear` layer before fine-tuning, providing a blank slate for the new dataset mappings, and restored the baseline learning rate. | 47c1103 |
| 014 | `Code/transfer.py` | Strict feature freezing results in severe underfitting (28% accuracy) during knowledge transfer. | The source domain (microscopic cells) and target domain (macroscopic CT organs) exhibit a significant semantic gap. Freezing the convolutional backbone prevented the filters from adapting to the new spatial textures. | Removed strict freezing to enable Full-Network Fine-Tuning. Passed `model.parameters()` to the target optimizer with a decayed learning rate (0.5x) and extended the horizon to 20 epochs for gentle domain adaptation. | 59da305 |
| 015 | `Code/transfer.py` | Model achieves target accuracy during training but suffers late-stage collapse, resulting in 48% test accuracy. | The fine-tuning learning rate (0.5x) was too aggressive without regularization, causing the optimizer to bounce out of the local minimum and overfit in the final epochs. | Reduced the fine-tuning learning rate multiplier to 0.1x, injected L2 regularization (`weight_decay=1e-4`), and reduced training horizon to 15 epochs to stabilize convergence. | a857130 |
| 016 | `Code/train.py` | Pipeline lacks the comprehensive statistical evaluation metrics required for the final Consolidated Benchmark Report. | The baseline runner only calculated raw accuracy, masking true model performance on imbalanced classes. | Integrated `sklearn.metrics` into `evaluate_test_set()` to calculate Macro Precision, Recall, and F1-score. Added dynamic channel alignment to support universally swapping 1-channel and 3-channel datasets. | 61bb2b3 |
| 017 | `Code/train.py`, `Code/models.py`, `Code/fit.py` | Severe late-stage overfitting causes test accuracy to plummet (57%) despite high peak validation accuracy (82%). | The testing framework evaluated the final chronological epoch rather than the optimal weights. Furthermore, `ResNet18` lacked dropout layers and the optimizer lacked L2 regularization. | Implemented state-dict checkpointing (`best_model.pth`) in `Trainer.fit()`, loaded best weights prior to evaluation, injected `nn.Dropout` into `ResNet18`, and applied `weight_decay=1e-4` to the Adam optimizer. | fc32653 |
| 018 | `config.json` | `ResNet18` exhibits severe validation overfitting on the `orgs` dataset (Peak Val: 84%, Test: 62.5%). | The deep, narrow residual architecture of ResNet18 is misaligned with the small scale of the `orgs` dataset, causing it to memorize validation quirks rather than generalizing. | Swapped the target architecture to `VGG16` to leverage its wider convolutional layers and aggressive native dropout, aiming for more robust spatial feature extraction. | 4a506a6 |
| 019 | `Code/models.py` | `VGG16` architecture instantiation fails at runtime with a `RuntimeError` due to incorrect channel dimensions in nested convolutional blocks. | The architecture construction loop hardcodes or misallocates the initial `in_channels` constraint across subsequent layers instead of dynamically tracking channel propagation. | Audited the `VGG16` feature extraction block to ensure sequential channel transitions scale dynamically from the input layer onward. | ecdfee8 |
| 020 | `Code/models.py` | `VGG16` initialization crashes with `NameError: name 'ConvBlock' is not defined`. | The architecture loop attempted to instantiate a custom convolutional helper class that was missing from the module scope. | Replaced the undefined `ConvBlock` reference with native, inline `nn.Conv2d`, `nn.BatchNorm2d`, and dynamic activation layers. | 5422aec |
| 021 | `Code/fit.py` | Over-parameterized models (e.g., VGG16) fail to converge on small datasets, while capable models (ResNet18) suffer from severe spatial memorization (validation overfitting). | The small scale of the `orgs` dataset provides insufficient spatial variance for robust feature generalization. | Engineered an on-the-fly Data Augmentation pipeline (`RandomHorizontalFlip`, `RandomRotation`) directly into the GPU training loop to artificially expand spatial variance and force robust anatomical learning. Reverted to `ResNet18` with an extended training horizon. | 383ee4d |
| 022 | `Code/models.py`, `Code/train.py` | Model suffers from severe underfitting (Train Acc: 66%, Test Acc: 55%) due to excessive compound regularization. | Combining Data Augmentation, L2 Weight Decay, and a forcefully injected Dropout layer conflicted with ResNet18's native Global Average Pooling and Batch Normalization design principles. | Removed `nn.Dropout` from `ResNet18`, removed `weight_decay` from the Adam optimizer, and adjusted the learning rate to `0.0005` to restore network capacity while relying on augmentation for spatial generalization. | d906dc8 |
| 023 | `config.json` | Single-model forcing leads to prolonged under/over-fitting cycles across diverse datasets. | Applying a unified architecture (ResNet18) to all datasets violates the deep learning principle of matching model parameter capacity to intrinsic dataset complexity. | Executed an architectural mapping strategy based on DL theory: paired deep ResNet with complex `chest` scans, regularized AlexNet with `orgs`, textural VGG with `lesions`, and lightweight EcoResNet with simple `cells`. | 16b38c9 |
| 024 | `run_benchmarks.py` | Manual configuration switching prevents scalable pipeline testing and wastes engineering hours. | Executing benchmark matrices manually is an anti-pattern that introduces human error and limits overnight evaluation capabilities. | Engineered an automated subprocess runner (`run_benchmarks.py`) to sequentially iterate through the optimal model/dataset pairings, ensuring GPU memory isolation between runs. | 789fc54 |
